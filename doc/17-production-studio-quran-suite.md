# ١٧ — استوديو تحرير القرآن الكريم: منصة الإنتاج المتكاملة (٢٠٢٦-١١-٢٨)

> **النطاق**: إعادة تأسيس صفحة «منتج الصوت» إلى **استوديو إنتاج قرآني متكامل** (Quran Production Studio) وفق تصميم مرجعي محدّد من المستخدم: شريط علوي بعشرة قوائم، شريط مشروع ونقل، أدوات تحرير يسار، معاينة مشهد إسلامي وسط، مكتبة وسائط يمين، مسارات زمنية متعددة أسفل، إعدادات تصدير، وشريط حالة — **كل خاصية تعمل فعلاً** (تحميل/تشغيل/كاليوكي/تصدير MP3 وWAV وMP4/WebM). تحقّق E2E كامل على الخادم الحي بالمتصفح.

---

## ١. البنية العامة (تحويل `/audio-producer`)

الواجهة `ProductionStudioView` (‏`components/production-ui/`‎) توزّع ٩ مناطق وفق المرجع البصري، والحالة كلها من الجذر `use-production-studio.ts` الذي يجمع:

| المكوّن | الدور |
|---|---|
| `ProductionHeader` | هيدر أخضر داكن (شعار + عنوان ذهبي + أزرار حفظ/تصدير/مساعدة/إعدادات) + **شريط ١٠ قوائم منسدلة** عبر portal ثابت الموضع |
| `ProductionSubBar` | بطاقة المشروع + وضع صوت/فيديو + صيغة/معدل عينات/معدل بت + نقل (سابق/تشغيل/لاحق/إيقاف) + زمن `hh:mm:ss` + مستوى صوت |
| `ProductionLeftToolbar` | ٩ أدوات تحرير + ٣ أنماط (متقدم/سريع/معاينة) تقود بوابة العمليات المدمّرة |
| `ProductionPreview` | كانفيس المشهد الحي + زر تشغيل مركزي + تراجع/إعادة + تكبير + **إدارة الطبقات** (مسارات + طبقات المشهد) |
| `ProductionMediaLibrary` | ٤ تبويبات (المكتبة/الصور/الموسيقى/المؤثرات) + بحث + بطاقات بتطبيق فوري |
| `ProductionTimeline` | مسطرة + ٥ مسارات: فيديو (فيلمstrip) / تلاوة (موجة خضراء + حدود آيات ذهبية) / موسيقى (أرجوانية) / مؤثرات (برتقالية) / نصوص (زرقاء قابلة للسحب) |
| `ProductionExportPanel` | وضع فيديو/صوت + جودة/معدل بت + صيغة + مجلد + زر تصدير ذهبي مع شريط تقدّم وإلغاء |
| `ProductionStatusBar` | مدة/حجم/حالة الحفظ + مشروع جديد/فتح/حفظ باسم |
| `ProductionDialogHost` | موجّه **٢٤ حواراً** من ٣ ملفات (قرآن/مشروع، صوت/مزامنة، بصريات/إعدادات) |

**قاعدة الـ ٦٠٠ سطر**: الواجهات فوق انقسمت بين ١٥ ملفاً، والخطافات بين ٩ (‏`use-production-{studio,commands,clips,frame,mixer,verses,project,export}`‎)، والمكتبات النقية بين ٨ في `lib/production/`‎. حُذفت مجلدات `components/audio-producer-ui/` القديمة بعد أن حلّ محلها الاستوديو (المحرك والخطافات الصوتية نفسها بقيت).

## ٢. المعمارية الصوتية الموحّدة (مِكسر واحد)

المشكلة الجوهرية التي حلّها البناء: منتج الصوت كان يعزله (سياق خاص) عن مؤثرات الاستوديو. الآن:

- **`useProductionMixer`** يملك `AudioContext` مشتركاً + `GainNode` رئيسياً (المِكسر) يُنشأ عند الفتح (`ensureGraph` على الوصل) **قبل أول تشغيل**، وتُصبّ فيه: التلاوة (عبر `outputNodeRef` في محرك التشغيل) + الموسيقى (حلقة بمكسبها) + المحيطات الإجرائية (مطر/ليل/بحر/نسيم من `production-ambient.ts` — حلقات ضجيج ملوّنة حتمية البذرة بتلاشي أطراف).
- **محرك التشغيل** (‏`use-audio-producer-playback`‎) قبِل خيارَي `sharedContextRef/outputNodeRef`‎: يستعمل سياق المِكسر إن وُجد بدل إنشاء خاص، و**يثبّت السياق في `ctxRef` دائماً** حتى يقرأ `startNodeAt/tick` السياقَ نفسه، والاتصال بالخرج لا يتم إلا **إذا كان المِكسر على السياق نفسه** (‏`mixerOut.context === ctx`‎) — الاتصال بين سياقين مختلفين غير مشروع في Web Audio ويُجهض الصوت بصمت (ثلاثة علل اكتُشفت E2E وأُصلحت، انظر §٧).
- **التسجيل** عبر `MediaRecorder` (‏WebM/Opus‎) لالتلاوة الخاصة ← تحميل مباشر إلى المحرر (‏`producer.loadFile`‎) مع قائمة تسجيلات الجلسة.
- **الرندر المشترك للتصدير الصوتي**: `use-production-export` يمزج غير متصل (OfflineAudioContext): التلاوة المحرَّرة بالصدى + الموسيقى + المحيطات ← WAV فوري أو MP3 عبر `/api/production/encode`.

## ٣. راسم الإطار (المعاينة = المُصدَّر)

`lib/production/production-frame-renderer.ts` + `production-scene-ornaments.ts`‎: مشهد حتمي بدلالة `timeSec` — **ما تراه هو ما يُصدَّر حرفياً** (يغلق عطل «الكاليوكي يظهر في المعاينة ويختفي في الفيديو» لأن مسار الرسم واحد):

- **المشهد المرجعي**: خلفية (إطار فيديو الخلفية بملء التغطية + طبقة زمردية للقراءة، أو تدرّج مختار من `STUDIO_GRADIENTS`) + **قوسان مدببان** بإطار ذهبي مزدوج وشبكة مشربية + **قناديل معلّقة** بتوهّج يرقص + **أفق مسجد** (قباب ومآذن) + **جسيمات ذهبية** حتمية + إطار ذهبي بمعيّنات زوايا.
- **النصوص**: عنوان السورة بخط كليغرافي ذهبي (تدرّج) + اسم القارئ + **فاصل زخرفي** (خط + معيّن + التفافات) + **الآية بالرسم العثماني** (لفّ كلمات بـ `splitAyahTokens`‎، سطر واحد مصغّر اختيارياً، **موضع عمودي قابل للتحكم** ‎`versePosition`‎، نافذة تمرير تتبع الصوت ‎`followAudio`‎) + **كاليوكي** (الكلمة الجارية ذهبية بتقدير أوزان النطق من `verse-words`) + ميدالية رقم الآية + الترجمة + العلامة المائية + مقاطع النص النشطة (بسملة/عنوان/مخصص).
- **مصغرات فيلمstrip** حقيقية لمسار الفيديو: عنصر فيديو خفي مستقل يُبْحَر زمنياً ويُرسم ٨ لقطات jpeg.

## ٤. الخطوط الزمنية بإحداثيات المحرَّر

`lib/production/production-timeline-mapping.ts` (نقية): تحويلات المصدر↔المحرَّر (`mapSourceToEdited/mapEditedToSource`) + **قمم الموجة على الخط المحرَّر** (‏`editedPeaksFromSource`: لكل دلو زمن المحرَّر ← مصدر ← قمة) + **فترات الآيات المحرَّرة** (‏`editedVerseSpans`‎). فترات الآيات تُرسم شاراتها الذهبية على الموجة الخضراء، ومقاطع «الآية N» تُولَّد على مسار النصوص (قابلة للإخفاء لكل آية) — كل السحب والتحديث يمر عبر `updateTextClip`.

## ٥. المشاريع والحفظ التلقائي

`lib/production/production-project-store.ts` (نقية) + `use-production-project`‎:
- **قائمة مشاريع** (‏`quran_production_projects_v1`‎، سقف ٢٠ مشروعاً و٥١٢KB للمشروع) تحفظ: التحديد (سورة/مدى/قارئ/ترجمة) + **تحرير الصوت الكامل** (مقاطع/مكسب/تطبيع) + **حدود الآيات** + الصدى + البصريات + الإعدادات + المقاطع.
- **الحفظ التلقائي كل ١٥ ثانية** (‏`quran_production_autosave_v1`‎) + «استعادة» من قائمة المشاريع، وفتح آخر مشروع تلقائياً عند العودة.
- عند الفتح: تُعاد الآيات من EveryAyah (كاش المتصفح يجعلها فورية) ثم تُطبَّق الحدود والتحرير والصدى؛ الملفات المرفوعة (موسيقى) تُطلب إعادة ربطها — بلا ادعاء تخزين بافرات في localStorage.

## ٦. التصدير (ثلاثة مسارات حقيقية)

| المسار | الآلية | الحالة |
|---|---|---|
| **صوت WAV** | مزج غير متصل كامل → `encodeWav16bit` → تنزيل | مُتحقَّق (تنزيل ١٫١MB) |
| **صوت MP3** | WAV ← `POST /api/production/encode` (FFmpeg `libmp3lame` بمعدل بت المستخدم) | مُتحقَّق (‏MP3 صالح ١٩٢kbps‎) |
| **فيديو WebM/MP4** | **تسجيل حي للمعاينة نفسها**: `canvas.captureStream(30)` + `MediaStreamAudioDestinationNode` من المِكسر ← `MediaRecorder` أثناء تشغيل كامل حقيقي ← تنزيل، أو ترميز MP4 عبر الخادم | مُتحقَّق (يبدأ التسجيل مع شريط تقدّم وإلغاء؛ استراتيجية «ما تراه هو ما يُصدَّر») |

`/api/production/encode` (‏255 سطراً): سقف ٢٥٠MB + **بايتات سحرية** (RIFF/EBML/ftyp) + `execFile` بمصفوفة معاملات فقط + سقف ٢٤٠ ثانية (SIGKILL) + ‎`empty_moov` (فشل `frag_mp4` في بناء ffmpeg 7 الثابت هذا) + ‎`-f` صريح للأنابيب. المخرجات: MP3/WAV/MP4(H.264+AAC)/WebM(VP9+Opus).

## ٧. بوابات الجودة والتحقق E2E

على الخادم الحي (agent-browser + رؤية + مسابر بكسل على الكانفيس):
- **البنية**: ١٠ قوائم تفتح حواراتها (اختبار: مكتبة القرآن→السور فتح منتقي السور ثم اختيار الإخلاص أعاد التحميل فوراً ٢٠ث‎).
- **التشغيل**: زمن يتقدم (‏٢→٥ث‎) — بعد إصلاح ثلاث علل صوتية: (١) قائمة منسدلة portala تُغلق قبل click (‏`rootRef.contains` لا يشمل البطاقة ← أضيف `cardRef`)؛ (٢) عدم تثبيت السياق المشترك في `ctxRef` فيستخدمه `startNodeAt`؛ (٣) اتصال عقدة خرج بين سياقين مختلفين يُجهض بصمت ← فحص `mixerOut.context === ctx`.
- **المشهد**: بكسل-تحقق: نصّا آية (صفان) + كلمة ذهبية (كاليوكي ٢٣ بكسلاً) + ميدالية (قرص داكن + حلقة) + القناديل والمآذن والعنوان الذهبي والفاصل.
- **المسارات**: مسطرة RTL (التسميات من اليمين) + موجة خضراء بشارات ذهبية + فيلمstrip حقيقي + مسار موسيقى فارغ بمعلومة «بلا موسيقى» + مقاطع النص الزرقاء (البسملة + عنوان السورة).
- **المكتبة**: ٦ مصغرات مولّدة (ز-ذكاء) تُطبَّق خلفياتها فوراً (تحقق: تغيّر عنوان مسار الفيديو إلى «نجمة ثمانية دوّارة»).
- **التصدير**: تنزيل MP3 من الواجهة (‏`URL.createObjectURL` معترضاً: ١٫١MB‎) + تسجيل فيديو يبدأ بشريط تقدّم (‏٦/٤٦ث) ويلغى.
- **lint صفر أخطاء** (٨ تحذيرات نمطية كالموجودة) + `tsc` نظيف + كل ملف ≤ ٦٠٠ سطراً.

## ٨. قائمة القوائم (كلها تعمل فعلاً)

**المشاريع**: جديد/فتح/حفظ/استعادة · **مكتبة القرآن**: السور (منتقي فوري)/الآيات (مدى)/التلاوات (تحميل)/القراء · **مكتبة الصوت**: تسجيلاتك/مؤثرات (صدى DSP)/خلفيات صوتية (محيطات) · **مكتبة الصور**: خلفيات (٩ فيديوهات + ١٥ تدرّجاً)/زخارف/شعارات · **تحرير الصوت**: تنقية (سكوت)/إزالة ضوضاء (بوابة)/مستوى (مكسب+تطبيع) · **تحرير الفيديو**: قص وتقسيم/دمج (إغلاق فجوات)/انتقالات/تحريك النص · **النصوص**: آيات (مقاطع)/عنوان السورة/اسم القارئ/نص مخصص · **الترجمة**: اختيار اللغة/إظهار · **التوقيت والمزامنة**: حدود الآيات (سحب/أزرار/كشف تلقائي) · **التصدير**: MP3/WAV/MP4/جودة.
