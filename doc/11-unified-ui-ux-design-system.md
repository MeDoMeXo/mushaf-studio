# ١١ · نظام التصميم والواجهة الموحّد (Unified Open-Source UI/UX Design System)

تم توحيد **كامل أركان منصة «مصحف الاستوديو»** (جميع المسارات الـ ٦، النوافذ الحوارية الـ ٣، شريط التنقل، ومشغل التلاوة العام) وفق هوية بصرية موحّدة ومعمارية واجهات احترافية مبنية على أفضل مكتبات **GitHub** مفتوحة المصدر لـ React وNext.js، مع توافق كامل للغة العربية (`dir="rtl"`)، المظهرين الفاتح والليلي، وإمكانية الوصول (`WCAG 2.2 AA`).

---

## ٢. قواعد اللغة البصرية الموحّدة (Visual Language Rules)

1. **شبكة العرض القياسية (`max-w-[1440px]`)**: توحيد الحد الأقصى للعرض الأفقي عبر الشريط العلوي (`Header`)، الصفحة الرئيسية (`HomeView`)، فهرس السور والقراء (`QuranIndexView`)، الاستوديو (`StudioView`)، ولوحة التحكم (`AdminView`).
2. **سطوح أحادية الارتفاع بخطوط شعرية (Single-Elevation Hairline Surfaces)**:
   - استخدام بطاقات `rounded-2xl` بحدود دقيقة (`border-[var(--border-hairline)]`) وخلفية `bg-[var(--surface-card)]` مع تباين واضح بين السطح الأساسي (`--surface-canvas`) والعناصر الفرعية (`--surface-subtle`).
3. **مساحات الداكن والتركيز البصري (Darkroom Preview Stage)**:
   - توحيد شبكة الخلفية الهندسية `.studio-stage-grid` حول مسرح المعاينة في الاستوديو (`StudioStagePanel`) وحول لوحة المعاينة الحية لافتراضيات الاستوديو داخل لوحة التحكم (`AdminView`).
4. **أشرطة التمرير المخصّصة (`.studio-scroll`)**:
   - تطبيق شريط تمرير رشيق متكيف مع الهوية البصرية في قوائم القراء بالاستوديو، نافذة اختيار القارئ، نافذة التصدير، جداول لوحة التحكم، ومعاينة JSON للنسخ الاحتياطي.
5. **محاذاة الأرقام (`tabular-nums`)**:
   - تطبيق `tabular-nums` على جميع العدادات، المدد الزمنية، نسب التقدم، أرقام السور، وبطاقات الإحصائيات لمنع اهتزاز التخطيط عند تحديث الأرقام.
6. **توحيد الأرقام الحية ديناميكياً**:
   - استبدال جميع العدادات النصية الثابتة ببيانات حية من الثوابت المركزية (`RECITERS.length` = **٣٨ قارئاً عالمياً**، `TRANSLATIONS.length` = **٦ ترجمات معتمدة من QUL**، `STUDIO_TEMPLATES.length` = **١٤ قالباً إسلامياً**).

## ٣. خريطة التوحيد عبر جميع أركان المشروع

| الركن / المسار | الملف | التحديثات الموحّدة المطبّقة |
|---|---|---|
| **السياق العام** | `components/AppProvider.tsx` | رفع `<StudioTooltipProvider>` و `<Toaster>` من `sonner` للجذر لخدمة جميع الصفحات والنوافذ دون تكرار |
| **الشريط العلوي** | `components/Header.tsx` | عرض `max-w-[1440px]`، شريط تنقل بمؤشر `layoutId="header-active-nav"`، `StudioTooltip` لمبدّل المظهر، وقائمة جوال متحركة بـ `AnimatePresence` |
| **شريط التلاوة العام** | `components/AudioPlayerBar.tsx` | ترقية شريط التقديم إلى **Radix UI Slider** (`dir="rtl"`)، تلميحات `StudioTooltip` على أزرار التحكم وتبديل القارئ والإغلاق |
| **نافذة القارئ العالمي** | `components/ReciterPickerModal.tsx` | ترقية كاملة إلى **Radix UI Dialog** + **Radix UI Tabs** بمؤشر `layoutId="reciter-picker-tab-indicator"` + `.studio-scroll` + تلميحات المفضلة والاستماع |
| **الصفحة الرئيسية (`/`)** | `components/HomeView.tsx` | إطار هيرو معماري بشبكة نقطية خفيفة، إحصاءات ديناميكية (`٣٨ قارئاً` · `٦ ترجمات`)، فلاتر **Radix Tabs** (`layoutId="home-place-filter-indicator"`)، زر مسح البحث |
| **فهرس السور والقراء (`/quran`)** | `components/QuranIndexView.tsx` | تبويبان رئيسيان بـ **Radix Tabs** (`فهرس السور` / `مكتبة القراء`) + دليل تفاعلي لـ ٣٨ قارئاً ببحث وتصفية حسب الرواية ونجوم المفضلة + فلاتر مكية/مدنية بـ `layoutId` |
| **قارئ السورة (`/quran/[id]`)** | `components/ReaderView.tsx` | شريط أوامر لاصق موحّد مع `StudioTooltip`، درج إعدادات متحرك بـ `AnimatePresence` يستخدم **`StudioSlider`** و **`StudioSwitch`**، احترام اتجاه الترجمة (`ltr`/`rtl`)، وتمرير `&translation=` عند الانتقال للاستوديو |
| **البحث الشامل (`/search`)** | `components/SearchView.tsx` | بطاقة بحث موحّدة `rounded-2xl`، أزرار اقتراحات بحث سريعة (`الحمد`، `الرحمن`، `الصبر`، `آمنوا`، `بذكر الله`)، شريط تقدم المسح، زر مسح، وتلميحات `StudioTooltip` |
| **الاستوديو (`/studio`)** | `components/StudioView.tsx` + `components/studio-ui/*` | تقسيم معياري إلى ٦ وحدات، شريط أوامر علوي، لوحة أوامر `Ctrl+K` (`cmdk`)، سجل **تراجع/إعادة** (`Ctrl+Z` / `Ctrl+Shift+Z`) بـ ٤٠ خطوة، مفتش تصميم بـ Radix Tabs/Accordion/Sliders/Switches، و**اختيار الترجمة المعتمدة من QUL (٦ ترجمات)** |
| **نافذة تصدير الفيديو** | `components/StudioExportModal.tsx` | ترقية إلى **Radix UI Dialog** (مع استمرار ميزة التصغير العائمة `minimized`)، استبدال جميع منزلقات الإعدادات بـ `StudioSlider` ومفتاح تلاشي الصوت بـ `StudioSwitch`، وعرض اسم الترجمة النشطة من QUL |
| **لوحة التحكم (`/admin`)** | `components/AdminView.tsx` | قائمة جانبية بمؤشر `layoutId="admin-nav-active"`، مبدّل ثيم افتراضي بـ `layoutId="admin-theme-mode"`، `StudioSlider` و `StudioSwitch` في إعدادات القراءة والاستوديو، معاينة حية داخل `.studio-stage-grid`، و `.studio-scroll` للجداول والنسخ الاحتياطي |

## ٤. اختصارات لوحة المفاتيح الموحّدة في الاستوديو

| الاختصار | الوظيفة |
|---|---|
| `Ctrl + K` أو `⌘ + K` | فتح لوحة الأوامر السريعة (`StudioCommandPalette`) للبحث في السور، القراء، القوالب، والترجمات المعتمدة |
| `Ctrl + Z` أو `⌘ + Z` | التراجع عن آخر تعديل في حالة الاستوديو (`Undo`) |
| `Ctrl + Shift + Z` أو `Ctrl + Y` | إعادة التعديل (`Redo`) |
| `Escape` | إغلاق أي نافذة حوارية مفتوحة (Radix Dialog أو لوحة الأوامر) |
