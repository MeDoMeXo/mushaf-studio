## Deviations from spec (with reasons)
1. **`TransitionRight` icon → `Blend`** for the video:transitions menu item: verified absent from the installed lucide-react 0.553 dist (no `transition-*.js` in dist/esm/icons). Blend is the closest semantic/visual substitute for transitions.
2. **WebM supported in encode route** (spec whitelist was mp3/wav/mp4 only): `ProductionExportFormat` includes 'webm' and the UI exposes WebM in the sub-bar + export panel, so rejecting it would create a dead-end; VP9+Opus args added.
3. **Header dropdowns render via portal (fixed-position)**: the spec's plain absolutely-positioned card would be vertically clipped by the menu strip's `overflow-x-auto` (overflow on one axis forces clipping on the other); portal preserves the intended visual.
4. **Lock icons in timeline label column are passive spans** (title `قفل المسار`), not buttons: the props contract has no lock handler — disabled/no-op buttons are worse a11y than a titled indicator.
5. **Text clip labels**: the contract has no verse-number on ProductionTextClip, so clips show their own text with per-kind fallbacks (البسملة/عنوان السورة/اسم القارئ/نص مخصص) instead of `الآية N`.
6. **Timeline canvases draw mirrored** (`x = w-1-i`): required for the waveforms/verse markers/gaps to align with the RTL time origin mandated by the insetInlineStart positioning convention (unmirrored drawing would reverse time).
7. **Sub-bar save-state**: `saveState` also disables the save button while 'saving' and swaps in a Loader2 spinner (spec only required the canSave gate); ruler zoom steps use `niceRulerStep(totalSec/zoomFactor)` so ticks stay ~5 visible at any zoom.
8. LucideIcon type not imported; used `type IconType = typeof <SomeIcon>` (same type for all lucide icons) to avoid relying on type-name exports.
