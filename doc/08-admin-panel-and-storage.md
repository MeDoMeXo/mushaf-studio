# ٠٨ · لوحة التحكم، الإحصائيات، ومفاتيح التخزين المحلي

تقع لوحة التحكم في المسار `/admin` (`components/AdminView.tsx`) وتعتمد على نظام تخزين محلي موحّد في `lib/storage.ts`.

---

## ١. المصادقة وحماية لوحة التحكم
- محمية برمز دخول رقمي (`PIN` — الافتراضي `1234`، قابل للتغيير من قسم الأمان عبر دالة التحقق النقية `validatePinChange`).
- تُحفظ الجلسة في `localStorage` (`quran_admin_session`) بمدة صلاحية **٨ ساعات**، وتنتهي تلقائياً بعدها أو عند النقر على «تسجيل الخروج».
- *(ملاحظة معمارية: هذه المصادقة محلية على مستوى المتصفح لعدم وجود قاعدة بيانات خادمية حالياً؛ راجع [`10-project-notes-and-roadmap.md`](./10-project-notes-and-roadmap.md) عند الترقية مستقبلاً لإضافة حسابات خادمية أو مفاتيح API).*

---

## ٢. أقسام لوحة التحكم الثمانية (`AdminSection`) والواجهة الموحّدة

تتبع لوحة التحكم نفس لغة الاستوديو البصرية (`max-w-[1440px]`، بطاقات `rounded-2xl` بخطوط شعرية، قائمة جانبية بمؤشر `motion` `layoutId="admin-nav-active"`، وعناصر **Radix `StudioSlider`** و **`StudioSwitch`** بدلاً من مدخلات المتصفح التقليدية):

| القسم | المعرّف | الوظائف المتوفرة |
|---|---|---|
| **١. نظرة عامة** | `overview` | بطاقات إحصائيات حية بأرقام `tabular-nums` (الزيارات، القراءات، التلاوات، التصديرات، عمليات البحث)، **رسم بياني تفاعلي على Canvas لآخر ١٤ يوماً**، سجل آخر الأحداث، وزر تصفير الإحصائيات |
| **٢. المحتوى** | `content` | تعديل اسم المنصة (`siteName`)، الوصف (`tagline`)، عنوان الهيرو (`heroTitle`)، الشارة (`badge`)، وتخصيص **«آية اليوم»** يدوياً (سورة + آية) أو إعادتها للدوران التلقائي اليومي |
| **٣. تذييل الموقع** | `footer` | تفعيل أو إخفاء فوتر الموقع (`footer.enabled`)، تعديل الوصف المختصر ونص الحقوق، تبديل الروابط السريعة وإشارة مصدر QUL، إضافة/حذف حتى ٦ روابط مخصّصة محققة أمنياً (`sanitizeFooterLinkHref`)، مع **معاينة فورية حية** |
| **٤. القراءة والاستماع** | `reading` | ضبط القارئ الافتراضي (`defaultReciter`)، الترجمة الافتراضية من QUL (`defaultTranslation`)، حجم خط الآيات الافتراضي عبر `StudioSlider`، وتفعيل/إخفاء الترجمة افتراضياً عبر `StudioSwitch`، مع جدول القراء المزوّد بـ `.studio-scroll` |
| **٥. افتراضيات الاستوديو** | `studio` | ضبط الخط الافتراضي، التدرج، حجم الخط (`StudioSlider`)، لون النص، العلامة المائية، وتذييل اسم السورة (`StudioSwitch`) مع **معاينة Canvas حية** داخل إطار `.studio-stage-grid` |
| **٦. المظهر والألوان** | `appearance` | اختيار الوضع الافتراضي (فاتح/داكن) عبر مبدّل متحرك (`layoutId="admin-theme-mode"`) وتخصيص اللون الأساسي (`primaryColor`) واللون الذهبي (`accentColor`) مع معاينة فورية وزر استعادة الافتراضيات |
| **٧. النسخ والدمج** | `backup` | تصدير نسخة احتياطية كاملة (`JSON`) لإعدادات الموقع والإحصائيات، معاينة JSON داخل `.studio-scroll`، استيراد ملف نسخة احتياطية ودمجه بأمان عبر `mergeSiteConfig()`، أو نسخ JSON للحافظة |
| **٨. الأمان** | `security` | تغيير رمز الدخول (`PIN`) بالتحقق من الرمز الحالي وطول الرمز الجديد (٤–٨ أرقام) وتأكيده، مع تسجيل الخروج |

## ٣. مرجع مفاتيح التخزين المحلي (`STORAGE_KEYS` في `lib/storage.ts`)

| المفتاح | النوع | الاستخدام |
|---|---|---|
| `quran_config_v1` | `SiteConfig` (JSON) | تكوين المنصة الكامل (العناوين، الألوان، الافتراضيات، آية اليوم) |
| `quran_stats_v1` | `SiteStats` (JSON) | الإحصائيات الكلية + جدول التجميع اليومي `daily[YYYY-MM-DD]` + سجل الأحداث `log` |
| `quran_custom_templates_v1` | `SavedCustomTemplate[]` | قوالب الاستوديو الخاصة بالمستخدم (تشمل الآن جميع خصائص الزخارف الإسلامية) |
| `qlast` | `LastReadInfo` | آخر سورة وآية تمت قراءتها (`surah`, `ayah`, `name`) |
| `qbookmarks_v1` | `BookmarkItem[]` | الإشارات المرجعية للآيات المحفوظة من القارئ |
| `qtheme` | `'light' \| 'dark'` | اختيار المظهر الفاتح أو الداكن |
| `qreciter` | `string` (slug) | القارئ النشط المعتمد في القارئ العام |
| `qfav_reciters_v1` | `string[]` | قائمة القراء المفضلين (المميّزين بنجمة) |
| `qtrans` | `number` | رقم الترجمة المختارة في القارئ |
| `qvsize` | `number` | حجم خط القارئ (`rem`) |
| `qshowtrans` | `'0' \| '1'` | إظهار أو إخفاء الترجمة في القارئ |
| `quran_admin_pin` | `string` | رمز الدخول للوحة التحكم |
| `quran_admin_session` | `{ t: number }` | طابع زمني لجلسة الدخول النشطة (صالحة ٨ ساعات) |

### أحداث النافذة المخصصة (Custom Events)
- `quran-config-updated`: يُطلق فور حفظ أو إعادة ضبط `SiteConfig` لتحديث `AppProvider` وجميع المكونات لحظياً.
- `quran-stats-updated`: يُطلق فور تسجيل أي حدث عبر `bumpStat()` لتحديث لوحة الإحصائيات مباشرة.

### مخزن كاش الصوت الدائم (Cache Storage API)
- الاسم: `mushaf-studio-audio-v1` (منفصل عن `localStorage` لتجنب سقف 5MB واستيعاب مئات ملفات MP3 بكفاءة).
