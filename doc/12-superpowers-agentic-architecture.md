### تفصيل المستويات الإلزامية:
1. **`using-superpowers`**: البوابة الإلزامية التي تُفعّل في بداية كل تفاعل وتمنع اتخاذ قرارات متسرعة.
2. **`brainstorming`**: استكشاف المتطلبات بدقة عبر أسئلة سقراطية وتجزئة التصميم قبل لمس الأكواد.
3. **`writing-plans`**: صياغة مهام ذرية صغيرة وقابلة للتحقق خطوة بخطوة.
4. **`executing-plans`**: قيادة التنفيذ الممنهج وفق الخطة دون تشتت.
5. **`test-driven-development` (TDD)**: حظر التعديل بدون اختبار فاشل يسبق التعديل (`bun test`).
6. **`systematic-debugging`**: فحص الأسباب الجذرية عبر 4 مراحل (إعادة الإنتاج ← العزل ← كشف السبب ← الإصلاح والتحقق).
7. **`verification-before-completion`**: تقديم البراهين العملية وإجراء الفحوص الشاملة قبل ادعاء النجاح.
8. **المهارات المساعدة (8 إلى 15):** عزل الوكلاء، مراجعة الأكواد، دمج الفروع، وإدارة مساحات العمل.

## 3. تكامل Graphify: الرادار المعماري والتحليل الشبكي

يعمل **Graphify** كمرجع معرفي إلزامي للوكيل بالتوازي مع مهارات Superpowers:

### أ. العقد المركزية الحساسة (God Nodes) في مصحف الاستوديو
كشف تحليل Graphify للمشروع عن المكونات الأكثر ارتباطاً وتأثيراً:
1. **`toArabicDigits()`** (54 علاقة): الدالة المركزية لتحويل الأرقام إلى الرسم المشرقي في المصحف.
2. **`StudioState`** (39 علاقة): كائن الحالة الشامل لكل عناصر وتصميمات استوديو التلاوات.
3. **`StudioView()`** (28 علاقة): الحاوية الرئيسية لواجهة الاستوديو.
4. **`runExportPipeline()`** (46 علاقة عبر مسارات التصدير): المحرك المسؤول عن إخراج وتوليد الفيديوهات.
5. **`RECITERS`** (22 علاقة): مصفوفة بيانات القراء الـ 38 والمسارات الصوتية.

### ب. بروتوكول فحص الأثر المعماري (Impact Analysis Protocol)
قبل تعديل أو إعادة هيكلة أي عقدة، يلتزم الوكيل بالآتي:
1. **فحص شبكة التبعيات:** مراجعة خريطة التبعيات عبر [`graphify-out/GRAPH_REPORT.md`](file:///c:/Users/PC/Desktop/quran/graphify-out/GRAPH_REPORT.md) أو الواجهة التفاعلية [http://localhost:3000/graphify/graph.html](http://localhost:3000/graphify/graph.html).
2. **تحديد نطاق التأثير (Blast Radius):** حصر كافة المكونات المعتمدة على الملف المستهدف لضمان عدم حدوث أي كسر غير مقصود (Breaking Change).
3. **منع دورات الاستيراد (Zero Import Cycles):** الحفاظ التام على النتيجة الحالية الصفرية (0 Import Cycles) في المعمارية.

## 4. ثوابت مصحف الاستوديو التراكمية

1. **سقف الـ 600 سطر للملف الواحد:**
   - فحص إلزامي عبر `bun run scripts/check-file-size.ts`.
2. **قداسة الرسم العثماني والتصميم العربي (RTL):**
   - حفظ نصوص المصحف بالرسم العثماني وعلامات الضبط الأصلية، والأرقام المشرقية، والاتجاه اليميني `RTL`.
3. **خط إنتاج الوسائط والفيديو (FFmpeg/FFprobe):**
   - استخدام دوال الكشف الذاتي المتينة `resolveFfmpegPath()` و `resolveFfprobePath()` عبر [`lib/export-job-helpers.ts`](file:///c:/Users/PC/Desktop/quran/lib/export-job-helpers.ts).
4. **المعايير القياسية للفحص:**
   - خلو كامل من أخطاء الأنواع: `bun run tsc --noEmit`.
   - اجتياز جميع وحدات الاختبار: `bun test` بنسبة 100%.
